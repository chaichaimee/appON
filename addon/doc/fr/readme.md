## Commandez votre espace de travail avec précision
**appOn** est l'outil ultime pour les utilisateurs de NVDA exigeants. Ne perdez plus de temps à chercher dans le menu Démarrer.

<br />

## La puissance de l'"Activation Intelligente"
Si votre application est déjà ouverte, appOn la met au premier plan et la **maximise automatiquement**.

<br />

## Deux façons de tout dominer
* **1. Liberté Totale:** Assignez vos propres raccourcis personnalisés dans NVDA.
* **2. Le Centre de Commande Intelligent:** Appuyez sur `Alt+Windows+A` pour le menu dynamique.

<br />

---

<br />

## L'expérience "Mission Impossible"
* **Multi-Lancement Dynamique:** Le menu reste ouvert pour lancer plusieurs outils à la suite.
* **Séquence d'Autodestruction:** Le menu se ferme et **détruit son propre processus après 30 secondes**.

<br />

## Commandes Clés

| Commande | Action |
| :--- | :--- |
| `Alt+Windows+A` | Appeler le menu intelligent appOn |
| `Escape` | Quitter le menu immédiatement |
