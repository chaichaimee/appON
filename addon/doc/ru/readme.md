## Управляйте рабочим пространством с точностью
**appOn** — это незаменимый инструмент для пользователей NVDA, ценящих скорость и интеллект.

<br />

## Сила «Умной активации»
Если приложение уже запущено, appOn мгновенно выводит его на передний план и **автоматически разворачивает**.

<br />

## Два способа управления
* **1. Полная свобода:** Назначайте собственные горячие клавиши в NVDA.
* **2. Командный центр:** Нажмите `Alt+Windows+A` для вызова динамического меню.

<br />

---

<br />

## Меню в стиле «Миссия невыполнима»
* **Динамический мультизапуск:** Меню остается открытым для запуска нескольких инструментов подряд.
* **Самоликвидация:** Меню завершает свой процесс через **30 секунд бездействия**.

<br />

---

<br />

## Основные команды

| Команда | Действие |
| :--- | :--- |
| `Alt+Windows+A` | Вызвать интеллектуальное меню appOn |
| `Escape` | Немедленно закрыть меню |

<br />

*Почувствуйте эволюцию управления приложениями. Ваши команды исполняются мгновенно.*
