## Керуйте робочим простором із хірургічною точністю
Досить витрачати час на пошуки в меню «Пуск» або захаращувати робочий стіл. **appOn** — це досконалий інструмент для користувачів NVDA, яким потрібна швидкість, інтелект і впорядкований робочий процес. Він не просто «відкриває» додатки; він координує все ваше цифрове середовище.

<br />

## Сила «Розумної активації»
Чому варто запускати другу копію Word, якщо одна вже відкрита? **appOn** побудований на базі інтелектуального виявлення. Якщо ваш додаток уже запущено, appOn миттєво виводить його на передній план та **автоматично розгортає на весь екран**. Якщо додаток не запущено, він знаходить виконуваний файл і запускає його за мілісекунди. Це розумно, швидко та зручно.

<br />

## Два шляхи до повного контролю
Незалежно від того, чи ви майстер клавіатури, чи поціновувач організованих меню, у нас є рішення:

* **1. Повна свобода (Жести введення):** Призначайте власні блискавичні гарячі клавіші для кожного окремого додатка через діалог «Жести введення» NVDA. Ваш робочий процес — ваші правила.
* **2. Інтелектуальний командний центр (Меню appOn):** Не хочете запам’ятовувати десятки клавіш? Натисніть `Alt+Windows+A`, щоб викликати динамічне меню.

## Досвід меню у стилі «Місія нездійсненна»
**Меню appOn** — це не просто список; це живий інтерфейс:

* **Інтелект версій:** Меню автоматично визначає та відображає точний номер версії ваших додатків (наприклад, "Microsoft Word 2021" або "Chrome 122.x").
* **Динамічний мультизапуск:** Меню залишається відкритим, дозволяючи запустити цілий набір інструментів за один сеанс.
* **Послідовність самознищення:** Меню автоматично закриється та знищить власний процес після **30 секунд** простою. Воно не залишає слідів у пам'яті.

## Основні команди

| Команда | Дія |
| :--- | :--- |
| `Alt+Windows+A` | Викликати інтелектуальне меню appOn (За замовчуванням) |
| `Escape` (У меню) | Негайно завершити роботу меню |
| `Власні клавіші` | Встановіть свої комбінації у Жести введення NVDA |
