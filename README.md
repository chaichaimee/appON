### appOn

**Author:** chai chaimee

**URL:** https://github.com/chaichaimee/appOn

---

### Description

appOn is a fast shortcut to access tools and programs on Windows 11. If the user-defined shortcut is pressed while the program is already open, it will switch to that window and bring it to the foreground.

---

### Information

Users must set up their own shortcuts using the **Input Gestures** menu. The add-on includes support for the following applications:

* Audacity
* Brave
* Chrome
* Command Prompt
* Control Panel
* Disk Cleanup
* Edge
* Everything
* Firefox
* Google Drive for Desktop
* Microsoft Excel
* Microsoft Word
* Notepad
* Notepad++
* PowerShell
* Reaper
* This PC
* Winamp
* Windows Defender
* WordPad
